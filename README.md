# 🚀 Smart City Data Pipeline (Azure Data Factory)

## 📌 Overview

This project demonstrates an end-to-end data engineering pipeline built using Azure Data Factory to process traffic and pollution datasets.

---

## 🏗️ Architecture

Bronze → Silver → Gold

---

## 🔹 Pipeline Flow

* Ingest raw data into Azure Data Lake (Bronze)
* Clean and filter data using Data Flow (Silver)
* Join datasets to generate final output (Gold)

---

## 🔧 Tools Used

* Azure Data Factory
* Azure Data Lake Storage
* Mapping Data Flows

---

## ⚙️ Key Transformations

* Column selection & renaming
* Filtering invalid values
* Schema standardization
* Inner Join transformation

---

## 📊 Output

Final dataset stored in Azure Data Lake for analytics
